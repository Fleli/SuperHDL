# Working in this repository

This is a personal learning project. The owner wants to understand
HDLs and compiler implementation and retain ownership of the design.

- Implement the owner's described design; do not independently make
  architectural decisions.
- If a request leaves algorithms, data structures, language semantics,
  or interfaces undecided, ask before implementing those choices.
- Suggestions and explanations are welcome, but suggestions are not
  authorization to implement them.
- Work on one file at a time. Keep changes limited to the requested task.
- Do not add dependencies, abstractions, features, or unrelated
  refactoring without explicit direction.
- If the requested design has a problem, explain it and let the owner
  decide how to proceed.
- Leave one indented blank line between the final statement in a block and
  its closing curly brace. Indent every blank line in a block to match that
  block.
